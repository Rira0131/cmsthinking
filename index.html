📊 대시보드

앱을 열면 가장 먼저 보이는 화면으로, 학기 일정과 내 작업 현황을 한눈에 확인할 수 있습니다.

📅 학기 캘린더
  • 현재 학기의 월별 세미나 일정을 카드 형식으로 보여줍니다.
  • 각 주차에 날짜 · 담당 선생님 · 테마명 · 완료 여부가 표시됩니다.
  • 완료 처리된 주차는 초록색으로 표시됩니다.
🗂️ INDEX 진척도
  • 사고력 교안의 전체 테마 대비 자료 작성 완료율을 그룹별(IG·Pre-WHY·WHY 등)로 보여줍니다.
  • 카드를 클릭하면 INDEX 페이지로 이동합니다.
📝 최근 작성된 수업 연구
  • 가장 최근에 저장된 교안 5개를 미리 보여줍니다.
  • 교안 제목을 클릭하면 해당 교안으로 이동합니다.
📅 세미나 일정

센터의 학기별 세미나 일정을 관리하는 페이지입니다. 월별로 나뉜 카드에서 주차별 수업 배정을 확인하고 편집할 수 있습니다.

✏️ 일정 편집 모드
  • 오른쪽 상단의 ✏️ 일정 편집 버튼을 누르면 편집 모드로 전환됩니다.
  • 각 주차의 날짜 · 선생님 · 테마명 · 방향을 직접 수정할 수 있습니다.
  • 슬롯(선생님 배정 행)을 추가하거나 삭제할 수 있고, 주차·월 단위로도 추가·삭제가 가능합니다.
  • 수정 후 💾 저장을 눌러야 Supabase에 저장됩니다. 다른 선생님의 화면에도 즉시 반영됩니다.
✅ 완료 처리
  • 각 주차 행의 체크박스를 클릭하면 해당 주차를 완료로 표시합니다.
  • 완료된 주차는 초록색으로 강조됩니다.
↺ 초기화
  • 일정을 원본 상태로 되돌립니다. 주의 — 모든 수정 내용이 삭제됩니다.
📚 수업 연구 자료

작성된 모든 교안을 검색·열람하는 페이지입니다. 상단 탭으로 사고력과 교과 교안을 구분하여 볼 수 있습니다.

🧠 사고력 연구자료 탭
  • CMS 사고력 세미나 교안 목록입니다.
  • 상단 레벨 칩(Pre-IG, IG-V, 1레벨…)을 클릭해 레벨별로 필터링할 수 있습니다.
📚 교과 연구자료 탭
  • 학교 교과 과정에 맞춘 교안 목록입니다.
  • 상단 학년/학기 칩(초1-1, 중3-1 등)으로 필터링할 수 있습니다.
🔍 검색 · 필터
  • 검색창: 테마명, 활동명, 내용 전체에서 검색합니다.
  • 작성자 필터: 특정 선생님의 교안만 볼 수 있습니다.
  • 내 센터만 보기: 본인 센터에서 작성한 교안만 필터링합니다.
📋 교안 카드
  • 카드를 클릭하면 활동 연구, 댓글 등 상세 내용이 펼쳐집니다.
  • 📽️ 발표: 슬라이드쇼 발표 모드로 전환합니다.
  • 🖨️ 출력: A4 인쇄용 페이지를 열어 출력 또는 PDF 저장이 가능합니다.
  • ✏️ 편집 / 📋 복사: 내 교안이면 편집, 다른 사람 교안이면 복사해서 내 교안으로 만들 수 있습니다.
  • 💬 댓글: 교안마다 피드백을 남기고 확인할 수 있습니다.
📽️ 슬라이드쇼 발표 모드
  • 교안을 전체화면 슬라이드로 발표할 수 있습니다.
  • 첫 슬라이드: 테마명 · 수업 목표. 이후 슬라이드: 활동별 연구 내용.
  • ←/→ 키 또는 화살표 버튼으로 슬라이드를 이동합니다. 무선 프레젠터도 지원합니다.
  • 활동에 유튜브 링크가 있으면 발표 중 → 키를 누를 때 영상이 자동 재생됩니다.
  • 🌙 다크 / ☀️ 라이트 버튼으로 테마를 전환합니다.
  • 📖 교재 버튼으로 등록된 교재 이미지를 옆 패널에 띄울 수 있습니다.
  • ESC 키 또는 ✕ 버튼으로 발표 모드를 종료합니다.
🗂️ INDEX

전체 교과 과정의 단원 목록을 한눈에 보고, 어느 단원에 교안이 있는지 확인하는 페이지입니다.

🧠 사고력 인덱스
  • CMS 사고력수학 전체 테마(IG·Pre-WHY·WHY 1~15레벨)를 코드별로 표시합니다.
  • 초록 셀 : 모든 테마에 교안 완비   노란 셀 : 일부만 작성됨
  • 테마명을 클릭하면 수업 연구 자료 페이지에서 해당 테마 교안만 필터링됩니다.
  • 상단 검색창으로 테마명을 빠르게 찾을 수 있습니다.
📚 교과 인덱스
  • 초등 1학년 1학기부터 공통수학 2까지 모든 단원을 섹션별로 보여줍니다.
  • 파란 셀 : 교안이 작성된 단원 (교안 수 표시)
  • 단원 셀을 클릭하면 수업 연구 자료 교과 탭에서 해당 단원 교안만 보여줍니다.
✏️ 자료 작성 / 편집

새 교안을 작성하거나 기존 교안을 수정하는 페이지입니다.

📝 새로 작성 탭 — 기본 정보
  • 교안 유형: 🧠 사고력 / 📚 교과 중 선택합니다.
    • 사고력: 레벨 · 테마명 · 교과 연계 · CMS과정 연계 필드가 활성화됩니다.
    • 교과: 학년/학기 드롭다운 → 단원 드롭다운이 표시됩니다.
  • 작성자: 로그인한 선생님 이름이 자동으로 입력됩니다.
  • 교재 수업 목표 / 교사 추가 목표: 수업 목표를 두 가지 관점으로 작성합니다.
  • 비고: 수업 시 참고사항, 건의사항 등을 자유롭게 입력합니다.
📎 교재 이미지 · 첨부파일 · 참고 링크
  • 교재 이미지: 교재 사진을 업로드하거나 Ctrl+V로 스크린샷을 바로 붙여넣을 수 있습니다. 발표 모드에서 옆 패널에 표시됩니다.
  • 첨부파일: pptx · pdf · hwp 등 파일(최대 20MB)을 첨부합니다.
  • 참고 링크: 유튜브 영상, 외부 자료 등 링크를 추가합니다. 발표 모드에서 클릭하면 영상이 바로 재생됩니다.
🎯 활동 목록
  • + 활동 추가로 활동 블록을 추가합니다. 드래그(☰)로 순서를 바꿀 수 있습니다.
  • 각 활동에는 활동명 · 워크북 연계 · 활동 시간(분) · 준비물을 입력합니다.
  • 활동 연구: 수업 아이디어, 발문, 풀이 등을 자유롭게 작성합니다.
    • 상단 툴바로 굵게 · 글자색 · 형광펜을 적용할 수 있습니다.
    • ∑ 수식 버튼으로 수학 수식을 입력할 수 있습니다.
  • 총 활동 시간이 90분을 초과하면 경고 표시가 나타납니다.
∑ 수식 입력
  • 활동 연구 툴바의 ∑ 수식 버튼을 클릭하면 수식 편집기가 열립니다.
  • 화면 터치 또는 클릭으로 가상 키보드를 이용하거나, 상단 프리셋 버튼(분수, 제곱, 루트, 시그마 등)으로 빠르게 입력할 수 있습니다.
  • LaTeX를 직접 입력하는 것도 가능합니다.
  • 기존 수식을 더블클릭하면 수정, 클릭 후 Delete로 삭제합니다.
✏️ 도형 그리기
  • 활동 연구 툴바의 ✏️ 도형 버튼을 클릭하면 도형 편집기가 열립니다.
  • 완성된 그림은 이미지로 삽입 버튼을 누르면 해당 활동의 이미지 목록에 추가됩니다.
  • 그리기 도구
    • ✏️ 스케치: 마우스를 드래그해 자유롭게 선을 그립니다.
    • ╱ 직선 / □ 사각형 / ○ 원: 드래그로 해당 도형을 그립니다.
    • T 텍스트: 클릭한 위치에 텍스트를 입력합니다. 치수나 길이를 기입할 때 사용합니다.
    • ↖ 선택: 도형을 클릭해 이동하거나 크기를 조절합니다. Delete 키로 선택한 도형을 삭제합니다.
    • ⬜ 지우개: 드래그한 부분을 흰색으로 덮어 지웁니다.
  • 기본 도형 삽입: 편집기 하단 행의 버튼을 클릭하면 도형이 캔버스 중앙에 바로 삽입됩니다.
    • 2D: 삼각형, 직각삼각형
    • 3D: 정육면체, 직육면체, 원기둥, 원뿔, 구, 삼각기둥, 사각뿔, 오각기둥, 육각기둥, 오각뿔, 육각뿔
    • 삽입 후 자동으로 선택 모드로 전환되어 바로 이동·크기 조절이 가능합니다.
  • 색상 / 선 두께: 검정·빨강·파랑·초록·주황 중 선택하고, 얇게·보통·굵게로 두께를 조절합니다.
  • 채우기: 활성화하면 사각형·원·기본 도형 안을 선택한 색으로 채웁니다.
  • ↩ 취소 또는 Ctrl+Z: 마지막 작업을 되돌립니다 (최대 20단계).
  • 🗑️ 전체: 캔버스 전체를 지웁니다.
📋 내 작성 자료 탭
  • 내가 작성한 교안 목록을 확인하고 편집하거나 삭제할 수 있습니다.
  • 전체 보기로 전환하면 다른 선생님 교안도 함께 볼 수 있습니다.
📤 자료 공유 탭
  • 내보내기: 내가 작성한 교안을 JSON 파일로 저장합니다.
  • 가져오기: 다른 선생님이 내보낸 JSON 파일을 불러옵니다. 중복 교안은 자동으로 건너뜁니다.
🌐 외부 링크
교안 자료실
  • CMS 선생님 포털의 교안 자료실로 이동합니다. 새 탭으로 열립니다.
📐 매쓰플랫
  • 매쓰플랫 교사 로그인 페이지로 이동합니다. 교과 수업에서 학생 문제 배정 등에 활용합니다.
⚙️ 기타 기능
🔑 비밀번호 변경
  • 사이드바 하단의 🔑 비밀번호 변경을 클릭해 비밀번호를 변경합니다. 새 비밀번호는 6자 이상이어야 합니다.
🔄 실시간 동기화
  • 교안 저장, 일정 변경 등 모든 데이터는 Supabase 클라우드에 저장되며, 같은 센터의 다른 선생님 화면에도 실시간으로 반영됩니다. 새로고침 없이 최신 내용을 확인할 수 있습니다.
🏢 센터 구분
  • 로그인 이메일 도메인에 따라 센터가 자동 구분됩니다(@mjcms.com · @drcms.com · @dbcms.com · @sbcms.com).
  • 수업 연구 자료는 전체 센터 교안을 기본으로 보여주며, 내 센터만 보기로 전환할 수 있습니다.
